You can get a relay channel name on Gen2+ Shelly devices using the Switch.GetConfig RPC method via an HTTP GET
 request to http://<device_ip>/rpc/Switch.GetConfig?id=<channel_index>.API RequestEndpoint
 
  URL: http://<device_ip>/rpc/Switch.GetConfig?id=0 
 
 (replace 0 with your target channel ID like 0, 1, etc.)
 
 Alternative JSON-RPC POST payload: {"id": 1, "method": "Switch.GetConfig", "params": {"id": 0}}

Gen1 firmware does not store or return custom names for individual channels via the local HTTP endpoint
 (/settings or /status). Custom channel names are entirely managed and saved by the Shelly Cloud application
  or your chosen smart home platform (like Home Assistant or HomeSeer).

On Gen1 Shelly devices (like the original Shelly 1, Shelly 2.5, or Shelly Plug), the local API does not use RPC commands.
 Instead, it uses a simpler, traditional URL-based system.
